# Scope and evidence levels

| Evidence | Supported statement | Unsupported leap |
| --- | --- | --- |
| Local unit probe | Adapter lifecycle and fixture-level equality behave as specified. | XPolicyLab transport works. |
| Official debug client | Serialization, decoding, server calls, keys, dimensions, and batch wiring execute. | Simulator task competence. |
| Simulator experiment | Declared task metrics under a pinned simulator configuration. | Sim-to-real transfer. |
| Physical experiment | Declared measurements on named hardware under a reviewed protocol. | General physical safety. |

Results should always name the highest evidence level actually executed.
